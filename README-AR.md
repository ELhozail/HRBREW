# תוצאות המבחן – באקדמיזציה בתיכון בשפה העברית

هذه نسخة GitHub Pages تعمل **برقم الهوية فقط** دون كود شخصي، وباللغة العبرية.

## كيفية تحديث الموقع الموجود في مستودع HRBREW

1. فك ضغط ملف ZIP.
2. افتح مستودع `HRBREW` ثم المجلد `docs`.
3. استبدل `docs/index.html` والملفات الثلاثة الموجودة تحت `docs/assets/` بالملفات التي في ZIP، مع المحافظة على المسارات.
4. من GitHub Settings > Pages تأكد أن الإعدادات `Deploy from a branch` و`main` و`/docs`.
5. بعد اكتمال النشر، افتح الرابط الرئيسي للموقع واضغط Ctrl+F5 عند الحاجة.

## ما الذي سيظهر؟
- يدخل الطالب رقم هويته الكامل (9 أرقام أو 10 أرقام للحالة الاستثنائية الموجودة).
- يظهر اسمه ورقم الهوية، والنتيجة `בתכנית` أو `לא בתכנית` فقط، بدون علامة رقمية.
- يحتوي الملف `docs/assets/encrypted-results.js` على 42 سجلًا مخزنًا بصيغة مشفرة وليس بنص واضح.

## تحذير خصوصية مهم جدًا
**رقم الهوية وحده ليس وسيلة تحقق آمنة.** يستطيع أي شخص يعرف رقم هوية طالب مشاهدة نتيجته، كما يمكن لمهاجم أن يحاول تخمين أرقام الهوية أو مهاجمة التشفير دون اتصال، لأن جميع الملفات متاحة للجمهور على GitHub Pages. استخدام PBKDF2 لتبطئة التخمين **لا يجعل هذا الحل آمنًا أو مناسبًا تلقائيًا لنشر نتائج طلاب حقيقية**. احصل على موافقة الإدارة المختصة واستعمل خدمة دخول خاصة إن كنت تحتاج حماية فعلية للبيانات. لا ترفع أبدًا ملف Excel أو CSV الأصلي علنًا.
